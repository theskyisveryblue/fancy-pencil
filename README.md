# Fancy Pencil

An independent, local-first spatial editor. Open, edit, and save `.pen` documents in your browser.

## Run

```sh
npm ci
npm run dev
```

## Check

```sh
npm run typecheck
npm test
npm run build
```

The document model is authoritative. Edits are saved locally in the browser. Share links and agent execution need a separately configured service; this repository contains no backend or API keys. Some imported effects and embedded websites have limited support. Demo files are original examples created for this repository.
